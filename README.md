# 🔬 AI Startup Validator

> Профессиональная валидация бизнес-идей через AI Customer Discovery по методологии **Mom Test**, глубокую **юнит-экономику**, вероятностное моделирование **Монте-Карло** и анализ **конкурентной среды**.

---

## 📌 Что это такое

**AI Startup Validator** — комплексный инструмент предварительной оценки стартап-идей для фаундеров и инвестиционных комитетов. За считанные минуты сервис:
1. Проводит симуляцию серии глубинных интервью по канонической методологии **The Mom Test** (Роб Фитцпатрик) без лести и ложноположительных сигналов.
2. Калибрует **юнит-экономику** (LTV, CAC, LTV:CAC, Payback period, Runway, Break-even) на основе отраслевых бенчмарков и страновых макропоказателей (World Bank API).
3. Запускает **вероятностное моделирование Монте-Карло** (500 сценариев на 24 месяца) для оценки реального риска банкротства.
4. Проводит **3-уровневый анализ конкурентной среды** и формирует стратегию дифференциации (УТП).
5. Рассчитывает взвешенный **Overall Viability Score** (0–100) на базе 3 независимых измерений.

## ✨ Возможности

| Модуль | Описание |
|---|---|
| 🧠 **AI Customer Discovery** | Синтез реалистичных персон и двухфазное Mom Test интервью через LLM API (Groq) |
| 💰 **Юнит-экономика** | Расчёт LTV, странового CAC, отношения LTV:CAC, окупаемости CAC и запаса прочности (Runway) |
| 📈 **Симуляция Монте-Карло** | 500 вероятностных траекторий MRR (P10, P50, P90), оценка вероятности банкротства и достижения $10k+ MRR |
| 🔍 **Конкурентный анализ** | Поиск прямых и косвенных альтернатив (каталог + DuckDuckGo Search + LLM-синтез) |
| 📊 **Живые бенчмарки** | Макроэкономические данные World Bank API + отраслевые отчёты (OpenView, a16z, Bessemer) |
| 💡 **Экспертные инсайты** | 15+ аналитических правил по методологиям Y Combinator и Шона Эллиса (Sean Ellis PMF Test) |
| 🏆 **Инвестиционный Score** | Сбалансированный скоринг жизнеспособности идеи (Problem / Solution / Finance) |
| 🌍 **Локализация** | Поддержка рынков Казахстана, СНГ и Global, мультиязычность (Русский / Қазақша) |

## 🛠 Технический стек

- **Backend**: Python 3.11+, Streamlit, Pydantic v2
- **Data & Math**: NumPy (векторизованный Monte Carlo), Pandas
- **LLM Engine**: Groq API (`llama-3.3-70b-versatile`) с пулом ключей и авто-ротацией при 429/quota
- **Поиск**: DuckDuckGo Search API (`ddgs`)
- **Макроданные**: World Bank REST API
- **Визуализация**: Plotly Graph Objects (веерные графики, pie charts)

## 🚀 Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Make-09/AI-startup-validator.git
cd AI-startup-validator

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Получить бесплатный API ключ Groq:
#    https://console.groq.com/ → API Keys → Create API Key

# 4. Добавить ключ в переменные окружения
export OPENAI_API_KEY=your_groq_key_here

# 5. Запустить веб-приложение
streamlit run main.py
```

├── feedback.py          — Модуль отправки отзывов

## 📋 Как пользоваться

1. Откройте приложение в браузере.
2. Введите название, подробное описание идеи и целевую аудиторию.
3. Выберите модель монетизации (Подписка / Оплата за использование / Комиссия со сделок).
4. Укажите финансовые параметры: стартовый капитал, ежемесячный маркетинговый и операционный бюджет.
5. Нажмите **«🔬 Запустить валидацию»**.
6. Изучите детальные ответы клиентов, финансовую юнит-экономику, вероятностный прогноз и рекомендации.
